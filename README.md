# Hi, I'm Katoemma! 👋

I'm a passionate **Full-Stack Developer & UI/UX Designer** specializing in building modern, scalable web and mobile applications. My expertise lies in creating seamless user experiences from concept to code, developing robust backend systems, and leveraging **AI-powered solutions**. I focus on the **VILT stack (Vue, Inertia, Laravel, Tailwind CSS)**, alongside **Nuxt.js**, **Flutter**, **TypeScript**, and **AI-powered RAG (Retrieval Augmented Generation)** using **LangChain.js with Google Gemini**.

## 🚀 What I Do

* **UI/UX Design**: Crafting intuitive and engaging user experiences, from wireframes and prototypes in **Figma** to polished designs showcased on **Dribbble**.
* **Frontend**: Building dynamic and responsive interfaces with **Vue.js**, **Nuxt.js**, **Inertia.js**, and **Tailwind CSS**.
* **Mobile**: Developing cross-platform mobile apps with **Flutter** and **Dart**.
* **Backend**: Building APIs and server-side logic using **Laravel (PHP)**, **Node.js (JavaScript/TypeScript)**, and **PHP**.
* **Full-Stack**: Combining frontend, backend, and database solutions for end-to-end development, with a particular strength in the **VILT stack**.
* **AI/ML**: Implementing **AI-powered solutions, including Retrieval Augmented Generation (RAG)** for enhanced conversational AI and information retrieval, specifically leveraging **LangChain.js with Google Gemini** models.
* **Open Source**: Creator of the **Airtable CRUD Flutter Package**, simplifying Airtable integration for Flutter apps.
